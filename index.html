    Supported formats

    Only formats tested on this build are listed here.

    FormatExtensionsPowered by
    PDF text.pdfpdf.js extraction, paragraphs joined, simple tables detected
    Word.docxMammoth plus Turndown
    PowerPoint.pptxBuilt-in parser (JSZip and slide XML)
    Excel.xlsx, .xlsSheetJS
    Web and e-books.html, .htm, .epubTurndown, plus a built-in EPUB parser
    Text and data.csv, .txt, .md, .json, .xmlBuilt-in converters
    Notebook.ipynbBuilt-in JSON parser

    Not supported: scanned PDFs and image OCR, audio transcription, and embedded images. Images inside documents are skipped. Simple PDF tables are detected from text positions; tables with wrapped cell text may still come out as lines.

    Your documents go nowhere

    Everything Markdoc needs comes from this same site, libraries included. Document contents are never sent, never stored, and leave memory when the tab closes. Check the Network tab in DevTools and see for yourself.
