    Tambahkan file untuk mulai. Load pertama mengunduh runtime Python dan library, jadi butuh waktu lebih lama.

    File dibaca browser, Python yang bekerja

    1

    Browser membaca file

    File yang kamu pilih dibaca lewat File API dan diteruskan ke worker di tab yang sama. Tidak ada request berisi dokumen ke server mana pun.

    2

    MarkItDown jalan di WebAssembly

    Di dalam worker, Pyodide menjalankan CPython dan library MarkItDown asli, versi 0.1.9, sama seperti yang kamu pasang lewat pip.

    3

    Hasil tinggal diambil

    Markdown tampil di panel graphite. Salin ke clipboard atau unduh sebagai file .md, lalu pakai untuk LLM, catatan, atau dokumentasi.

    Format yang didukung

    Daftar ini hanya berisi format yang sudah diuji jalan di build browser ini.

    FormatEkstensiMesin di baliknya

    Belum didukung di build browser ini: PDF hasil scan, OCR gambar, transkripsi audio, dan deskripsi gambar otomatis, karena ketiganya butuh model tambahan di luar WebAssembly. Tabel PDF kompleks juga bisa kurang rapi tanpa jalur pdfplumber.

    Dokumenmu tidak ke mana-mana

    Yang diunduh browser saat pertama kali memakai Markdoc hanyalah kode: runtime Pyodide dari CDN dan wheel Python dari PyPI. Isi dokumen tidak terkirim, tidak disimpan, dan hilang dari memori saat tab ditutup. Cek sendiri lewat tab Network di DevTools.

    Kenapa load pertama lama?

    Browser perlu mengunduh interpreter Python versi WebAssembly beserta library MarkItDown, totalnya puluhan megabyte. Kunjungan berikutnya lebih cepat karena file-file itu tersimpan di cache browser. File spreadsheet memuat pandas secara terpisah saat pertama kali dibutuhkan.

    Apakah hasil convert-nya sama dengan MarkItDown di pip?

    Sama untuk format yang didukung, karena yang berjalan memang library yang sama. Dua pengecualian kecil: deteksi tipe file mengikuti ekstensi yang kamu berikan, dan PDF memakai jalur pdfminer, bukan pdfplumber.

    Browser apa yang dibutuhkan?

    Browser modern dengan WebAssembly dan Web Worker, misalnya Chrome, Edge, Firefox, atau Safari versi terbaru. Di ponsel bisa, hanya saja load pertama lebih terasa.
